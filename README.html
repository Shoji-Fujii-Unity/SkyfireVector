日本語

SINGLE FILEWEBGLMOBILE OK

3Dフライトシューティングゲーム。単一の HTML ファイル完結で、ブラウザがあれば PC でもスマートフォンでも遊べます。

特徴

  • 🛩️ 3Dフライト：Three.js による無限生成地形（山岳・海岸）・雲・追従カメラ
  • 👾 敵機3種：戦闘機 / エリート / 爆撃機。ウェーブが上がるほど強化
  • 🎯 機関銃＆誘導ミサイル：赤い LOCK 枠でホーミング（リード誘導・自動再ロック）
  • 📱 スマホ対応：仮想スティック + FIRE / MSL / BST ボタン、横画面推奨
  • 🔊 サウンド On/Off：WebAudio 合成音、M キーでも切替、設定は保存
  • 🌍 多言語対応：日本語 / English / 简体中文 / 한국어 / Español（自動検出）
  • 💾 ローカルセーブ：ハイスコアTOP5・難易度・累計戦績を localStorage に保存

動作環境

  • WebGL2 対応の最新ブラウザ（Chrome / Edge / Firefox / Safari）
  • インターネット接続（Three.js を CDN から読み込みます）

遊び方

  1. index.html をブラウザで開く。スマホから遊ぶ場合はローカル配信：
    python -m http.server 8000   # http://<PCのIP>:8000/
  2. タイトル画面で難易度・言語・サウンドを選択 → 発進

攻略ヒント

  • 赤い LOCK 枠に捉えてからミサイル発射 → 自動追跡
  • 環状ピックアップ：緑＝装甲 / 橙＝ミサイル弾数
  • 40秒ごとにウェーブ上昇。敵の数・性能が増加

セーブデータ

ブラウザの localStorage（キー: skyfire_vector_save_v1）に保存。消去は DevTools → Application → Local Storage から。

技術構成

  • Three.js r160（CDN・ES Modules / importmap）
  • WebAudio API による効果音・エンジン音のリアルタイム合成
  • 外部アセットなし（メッシュ・テクスチャ・音声はすべてコード生成）

English

A 3D flight shooter in a single HTML file — playable on desktop and mobile browsers.

Features

  • 🛩️ Infinite procedural terrain, clouds and chase camera (Three.js)
  • 👾 3 enemy types: Fighter / Elite / Bomber, scaling by wave
  • 🎯 Guns & homing missiles with lead targeting and auto re-lock
  • 📱 Virtual stick + FIRE / MSL / BST buttons (landscape recommended)
  • 🔊 Synthesized sound with persisted On/Off toggle · 🌍 5 languages · 💾 Local high-score save

How to play

  1. Open index.html (mobile: serve via python -m http.server 8000)
  2. Pick difficulty / language / sound → LAUNCH
